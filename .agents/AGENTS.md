# Project Rules

## AI Usage Logging Rule
Whenever you make code changes in this project, update `AI_USAGE_LOG.md`.

For every task, record:
1. Date and time
2. Task/request
3. AI model used, if available
4. Purpose of using AI
5. Files created
6. Files modified
7. Files deleted
8. Important changes made
9. Tests/verification performed
10. Human review status

Do not overwrite previous entries.
Append a new entry for every completed task.

Keep the log concise and factual.
If the exact model or token usage is unavailable, write "Not available" instead of guessing.

Before finishing a coding task, always update `AI_USAGE_LOG.md`.
